# 📊 E-Commerce Sales & Profit Analysis Dashboard

Hey there! 👋 Welcome to my E-Commerce Data Analytics project. 

I built this interactive Power BI dashboard to dive deep into e-commerce data, uncover key business insights, and track overall profitability. Since I received a clean and structured dataset for this analysis, my main focus was entirely on transforming raw numbers into meaningful visual stories—optimizing data models, designing clean UI layouts, and extracting actionable insights.

---

## 🎯 What This Dashboard Solves
The goal of this project is to help stakeholders quickly understand business performance at a glance. It answers critical business questions like:
* Who are our top-performing customers and regions?
* Which product sub-categories are actually driving the most profit?
* How are monthly sales and profits fluctuating over time?

---

## 🛠️ Tools & Tech Stack
* **Power BI:** Used for data modeling, creating DAX measures, designing the layout, and building interactive charts.
* **Dataset:** A clean, structured e-commerce dataset optimized for reporting and analysis.

---

## 💡 Key Highlights & Features
* **Executive KPI Cards:** Instant visibility into Total Sales Amount, Total Profit, Total Quantity, and Average Order Value (AOV).
* **Customer & Regional Insights:** Tracked top buyers and state-wise performance trends using clean area and line charts.
* **Category & Payment Analysis:** Visualized product category shares alongside preferred payment modes (COD, UPI, Cards, EMI).
* **Profitability Breakdown:** Highlighted monthly profit/loss trends and top-performing sub-categories using modern bar and column charts.

---

## 🎨 Design & Aesthetics
I wanted this dashboard to look sleek and modern, so I went with a **dark-theme aesthetic**, paired with consistent color palettes, clear data labels, and neatly styled cards to ensure a clean user experience.
